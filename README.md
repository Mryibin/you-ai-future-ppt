# 你 + AI = 未来

> 面向大学新生的 AI 科普讲座 · 网页版 PPT（70 页 / 9 大板块 / 120–150 分钟）
> 主讲：周轶彬 · 2026 开学季

## ✨ 亮点

- **70 页完整讲稿**，从「AI 的想象力测试」到「未来 7 天行动计划」
- 电子杂志视觉风格：Noto Serif 衬线标题 + WebGL 流体背景 + 逐项动画
- **单文件放映**：无需任何安装，浏览器打开即用，可全屏、可键盘翻页
- 适配任意宽屏：内容自动等比例缩放，图片不遮挡文字（≥800px 宽窗口）

## ▶️ 快速开始

### 方式一：本地打开（推荐）

直接用浏览器打开 `index.html`，按 `F11` 进入全屏即可放映。

### 方式二：GitHub Pages 在线放映

仓库已启用 GitHub Pages，访问：

```
https://Mryibin.github.io/you-ai-future-ppt/
```

### 放映操作

| 按键 | 功能 |
|---|---|
| `→` / `Space` | 下一页 |
| `←` | 上一页 |
| `B` | 关闭/开启入场动画（低功耗模式，截图/录屏建议先按 B） |
| 点击右下角圆点 | 跳转任意页 |
